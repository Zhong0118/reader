# 图书详情、标签与筛选

图书库的“全部图书”支持网格和列表视图，右上角“批量”进入多选模式。单击图书打开详情，双击进入阅读。

标题、作者、评分、备注、出版信息和简介在图书详情中编辑。文本字段沿用论文详情的保存逻辑，失焦保存；单行字段支持回车保存、Escape 恢复。旧的“编辑文档信息”弹窗及其入口已移除。

标签直接复用论文详情的标签组件和添加弹窗。详情中只显示真实标签；点击标签筛选对应图书，点击 × 移除，点击 + 添加或选择已有标签。标签最多 30 个，每个 1–40 个字符，按大小写不敏感的名称去重，不接受空标签或控制字符。标签修改不改变最近阅读时间。

PDF 图书信息显示解析任务返回的总页数，优先使用后台版面解析的总页数；尚未获取页数时显示“—”。EPUB 不显示固定页数。

原“书籍／文章／论文”内容类型已从图书界面的展示、编辑和筛选中移除，卡片下方也不再显示类型、统计和编辑按钮。用量统计保留在操作菜单。文件格式 PDF / EPUB、图书库／论文库归属及论文详情中的书目类型不受影响。历史 `category`、分类状态和服务端接口仍保留以兼容已有数据，本次未删除数据库列或后台分类实现。

筛选支持文件格式、阅读状态、收藏、关键词和多个标签的组合条件。多个标签采用“同时包含”，关键词搜索标题、作者和标签。支持最近打开、最近导入和标题排序；筛选与视图保留在本次应用会话中。

## 手动检查

1. 单击图书打开详情，编辑标题、作者和出版信息，失焦后确认已保存。
2. 添加和删除标签，再点击标签，确认书库显示带此标签的图书。
3. 打开已开始解析的 PDF，确认详情显示总页数；EPUB 不显示页数。
4. 确认侧栏显示“全部图书”，右上角显示“批量”，卡片和菜单不再出现旧编辑入口或内容类型。
5. 切换网格／列表，检查长标题、长标签及浅色／深色外观。
